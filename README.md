按周记录 Python 算法练习，保留代码、每日笔记和周复盘。重点不是累计题数，而是追踪当时的问题、修正思路，以及后来能否独立复现。

## 阅读方式

1. 从每周的 `README.md` 看学习路线和当天索引。
2. 从 `dayXX/dayXX_学习总结.md` 看当时遇到的问题、语法疑问和方法推导。
3. 打开对应的 `.py` 文件，遮住解法重新实现，再对照注释。
4. 回到周复盘检查易错点和下一次独立练习清单。

后续学习周会继续加入 `2026/` 下，每周一个日期范围文件夹；跨年份时新建对应年份目录。每天的解法和笔记放在该周的 `dayXX/` 中，周末补一份周复盘。

部分思路参考了公开题解或学习交流中提供的代码；已知的题解链接列在 [参考来源](./SOURCES.md)。代码文件中的节点定义方便本地运行，力扣提交时可使用题目内置定义。
