## 一、有序数组转换为二叉搜索树

选择当前数组中间的元素当根，左边元素构造左子树，右边元素构造右子树。每次左右两侧节点数量最多相差 1，所以得到高度平衡的二叉搜索树。

### 切片法：你最先学习的写法

```python
m = len(nums) // 2
left = self.sortedArrayToBST(nums[:m])
right = self.sortedArrayToBST(nums[m + 1:])
return TreeNode(nums[m], left, right)
```

- `nums[:m]`：从下标 0 取到 `m - 1`，不包含 `m`。
- `nums[m + 1:]`：从 `m + 1` 取到末尾，包含起始下标。
- `left`、`right` 保存递归构造的**左右子树根节点**，不是单个数值。

用 `[1, 2, 3, 4, 5]` 走一遍：第一次选 `3`；左侧 `[1, 2]` 选 `2`，其左孩子是 `1`；右侧 `[4, 5]` 选 `5`，其左孩子是 `4`。

```text
      3
     / \
    2   5
   /   /
  1   4
```

递归先把左、右子树各自构造完成；每一层最终返回当前子树的根节点。切片表达清晰，但复制列表使时间复杂度为 `O(n log n)`，额外切片空间总计 `O(n)`。

### 下标范围法：由 Java 代码改写

```python
root = self.dfs(nums, 0, len(nums) - 1)
```

`lo`、`hi` 是当前范围的左右下标，均包含在范围内：

```python
if lo > hi:
    return None

mid = lo + (hi - lo) // 2
root = TreeNode(nums[mid])
root.left = self.dfs(nums, lo, mid - 1)
root.right = self.dfs(nums, mid + 1, hi)
return root
```

它一直使用同一个 `nums`，只调整下标，不复制子列表。时间 `O(n)`，递归栈空间 `O(log n)`。偶数长度时，这份代码选中间偏左的元素；切片版的 `len(nums) // 2` 选中间偏右的元素。两种结果都符合题目要求。

## 二、验证二叉搜索树：前序传递上下界

当前节点的值 `x` 必须满足祖先传下来的严格范围：

```python
left < x < right
```

递归进左子树时，将上界改成 `x`；进右子树时，将下界改成 `x`：

```python
self.isValidBST(root.left, left, x)
self.isValidBST(root.right, x, right)
```

例如根是 `10`，它的左子树**所有节点**都必须小于 `10`，不只是左孩子。因此只比较当前节点与直接孩子不够。严格 `<` 也表示重复值不符合本题的二叉搜索树定义。空节点返回 `True`，因为它不会违反范围。

初始上下界分别是负无穷和正无穷；代码中用 `from math import inf` 导入 `inf`。时间 `O(n)`，递归栈 `O(h)`，其中 `h` 为树高。

## 三、二叉树的最近公共祖先

递归函数向父节点返回：当前子树中找到的 `p`、`q`，或已经确定的公共祖先；都没找到则返回 `None`。

```python
if root is None or root is p or root is q:
    return root
```

这里用 `is` 判断是不是**同一个节点对象**。如果 `root` 本身就是 `p` 或 `q`，它也可能是最近公共祖先。

左右子树递归归来后：

| 左边结果 | 右边结果 | 本层返回 |
| --- | --- | --- |
| 有 | 有 | 当前 `root`，两目标分别在两侧 |
| 有 | 无 | 左边找到的节点，继续向上交付 |
| 无 | 有 | 右边找到的节点，继续向上交付 |
| 无 | 无 | `None` |

题目保证 `p`、`q` 都在树中。若没有这条保证，只有一边找到目标时，还需要额外确认另一个目标确实存在。时间 `O(n)`，递归栈 `O(h)`。

## 四、二叉搜索树中第 K 小的元素

二叉搜索树的中序遍历顺序是从小到大：左子树、当前节点、右子树。`k` 表示还要访问多少个节点；每访问一个节点就减 1，减到 0 时记录当前值。

```python
dfs(node.left)
if k == 0:
    return

k -= 1
if k == 0:
    ans = node.val
    return

dfs(node.right)
```

你原来的思路正确。增加左子树递归后的 `if k == 0: return`，是为了在答案已找到时，不让返回到父节点的代码继续执行 `k -= 1`。

`k` 和 `ans` 定义在外层 `kthSmallest` 中，内层 `dfs` 要给它们重新赋值，因此使用 `nonlocal k, ans`。这与 `ans` 为列表、只调用 `ans.append(...)` 的情况不同。题目保证 `k` 有效；`ans = 0` 是初始占位值，找到第 K 个节点后会被覆盖。

时间 `O(h + k)`，最坏 `O(n)`；递归栈空间 `O(h)`。

## 今天的递归共同点

先确定函数给调用者返回什么：构造树返回子树根节点，验证树返回布尔值，公共祖先返回节点或 `None`；第 K 小的辅助函数不返回结果，而是更新外层的 `k` 和 `ans`。理解返回值在上一层如何使用，比只记住递归调用语句更重要。
