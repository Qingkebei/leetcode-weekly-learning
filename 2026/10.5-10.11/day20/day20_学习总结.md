## 二、35. 搜索插入位置

`left`、`right` 组成当前仍需查找的闭区间。`(left + right) // 2` 取整数中点；`//` 是向下取整的除法。若 `nums[mid] < target`，目标只能在右边，令 `left = mid + 1`；否则保留左侧，令 `right = mid - 1`。

```python
while left <= right:
    mid = (left + right) // 2
    if nums[mid] < target:
        left = mid + 1
    else:
        right = mid - 1
return left
```

循环结束时，`left` 是第一个大于或等于 `target` 的位置，也就是找到目标的下标或应插入的位置。例如 `[1, 3, 5, 6]` 中查找 `2`，返回 `1`。时间 `O(log n)`，额外空间 `O(1)`。

## 三、74. 搜索二维矩阵

本题每一行递增，且下一行的第一个数大于上一行的最后一个数，所以可以把整个 `m × n` 矩阵看成一个升序的一维数组，在下标 `0` 到 `m * n - 1` 上二分。

```python
x = matrix[mid // n][mid % n]
```

这里 `n` 是**每行的列数**。把一维下标 `mid` 除以 `n`：商 `mid // n` 是行号，余数 `mid % n` 是列号。例如每行 4 列时，`mid = 6`，`6 // 4 = 1`、`6 % 4 = 2`，对应第 1 行第 2 列（从 0 开始数）。随后像普通二分一样，根据 `x` 与 `target` 的大小移动左右边界。时间 `O(log(mn))`，额外空间 `O(1)`。

注意不要与以前练习过的 **240. 搜索二维矩阵 II** 混淆：那题仅保证每行、每列分别有序，不能直接把整个矩阵按行展开后当成整体升序。
