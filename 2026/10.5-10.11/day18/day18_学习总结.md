## 一、腐烂的橘子：多源 BFS

### 题目中的“同时扩散”

所有初始腐烂橘子都在第 0 分钟开始扩散，因此扫描网格时把它们**全部**加入初始队列 `q`。`fresh` 记录新鲜橘子数；遇到 `1` 就加一，遇到 `2` 就记录坐标。

```python
for i, row in enumerate(grid):
    for j, x in enumerate(row):
        if x == 1:
            fresh += 1
        elif x == 2:
            q.append([i, j])
```

队列中的坐标是一整层，也就是**同一分钟已经腐烂、接下来可以向邻格传播的橘子**。`tmp = q; q = []` 保存当前层，并用新列表收集下一分钟腐烂的橘子。此时 `tmp` 仍指向原列表，不会因 `q = []` 而被清空。

```python
while q and fresh:
    ans += 1
    tmp = q
    q = []
    for x, y in tmp:
        for i, j in (x - 1, y), (x + 1, y), (x, y - 1), (x, y + 1):
            if 0 <= i < m and 0 <= j < n and grid[i][j] == 1:
                fresh -= 1
                grid[i][j] = 2
                q.append([i, j])
```

`ans += 1` 表示开始下一分钟的传播。当前层的每个橘子只访问上下左右四邻格；只有邻格仍是新鲜橘子 `1` 才处理。立刻把它改成 `2`，可以防止同一分钟从两个方向重复入队、重复减少 `fresh`。新加入 `q` 的坐标留到下一轮 `while`，因此时间一层一层增加。

`while q and fresh` 说明队列空了或没有新鲜橘子了就停止。结束后若 `fresh > 0`，表示仍有橘子无法被感染，返回 `-1`；否则返回经过的分钟数 `ans`。若一开始没有新鲜橘子，循环不执行，答案为 `0`。

### 与岛屿数量 DFS 的联系

Day 17 的岛屿题从一个 `1` 出发，DFS 把整座岛标记完；它只关心连通范围。本题要算传播的最早分钟数，且可能同时从多个 `2` 出发，所以把全部起点放入队列，按层扩散更直观。

## 二、课程表：DFS 判断有向图是否有环

`[a, b]` 表示先学课程 `b`，才能学课程 `a`，所以建一条从 `b` 指向 `a` 的边：

```python
g = [[] for _ in range(numCourses)]
for a, b in prerequisites:
    g[b].append(a)
```

例如 `[[1, 0], [2, 1], [0, 2]]` 得到 `0 → 1 → 2 → 0`。沿课程依赖走一圈又回到原课程，便无法安排学习顺序。

### 三种颜色

| `colors[x]` | 含义 |
| --- | --- |
| `0` | 尚未访问课程 `x` |
| `1` | 正在本次 DFS 的路径上，尚未处理完 |
| `2` | 课程 `x` 及其后续依赖都已处理完，未发现环 |

进入 `dfs(x)` 时先设为 `1`；遍历 `g[x]` 中的后续课程 `y`。如果 `y` 已是 `1`，说明从当前路径又走回路径上的节点，发现环；如果 `y` 是 `0`，递归查看它是否能发现环；`y` 为 `2` 时不用再查。

```python
def dfs(x: int) -> bool:
    colors[x] = 1
    for y in g[x]:
        if colors[y] == 1 or (colors[y] == 0 and dfs(y)):
            return True
    colors[x] = 2
    return False
```

这里 `dfs(x)` 返回 `True` 的含义是**发现环**，与外层 `canFinish` 的返回值含义相反。Python 中 `and` 的优先级高于 `or`，括号只帮助读清判断。只有把后续课程都查完且没发现环，才能把 `x` 改成 `2`。

外层扫描所有课程，是因为依赖图可能有几个互不相连的部分：

```python
for i, c in enumerate(colors):
    if c == 0 and dfs(i):
        return False
return True
```

例如 `0 → 1 → 2 → 0`：从 `0` 出发，`0、1、2` 依次标记为 `1`；在 `2` 的邻接表里再次看到颜色为 `1` 的 `0`，立即报告有环，最终 `canFinish` 返回 `False`。若没有环，每个节点只进入 DFS 一次，每条边只检查一次，时间为 `O(课程数 + 依赖条数)`；额外空间用于图、颜色数组和递归栈。

### 10 月 10 日复习：自己写的注释与修正

这次复习已经能自己写出建图、三色 DFS 和外层扫描的主干，也指出了两个函数的布尔值含义不同。把注释改得更精确后，关键部分可以这样读：

```python
def dfs(x: int) -> bool:
    colors[x] = 1  # x 进入当前 DFS 路径
    for y in g[x]:
        if colors[y] == 1:  # y 仍在当前路径上，出现环
            return True
        elif colors[y] == 0 and dfs(y):  # y 尚未被任何 DFS 访问；递归发现环
            return True
    colors[x] = 2  # 所有后续课程检查完，x 才算完成
    return False  # 从 x 出发没有发现环

for i, color in enumerate(colors):
    if color == 0 and dfs(i):
        return False  # dfs 为 True 表示有环，所以课程无法全部学完
return True  # 每一部分都检查过，且没有环
```

“`colors[y] == 0`”应理解为 `y` 从未被访问，不只是“还没被当作外层起点”。`colors[x] = 2` 与 `return False` 必须放在整个 `for y in g[x]` 结束之后；由 `dfs(x)` 负责标记 `x`，不在父层替它标记 `y`。外层 `enumerate(colors)` 逐个取得课程下标与当时的颜色；一次 DFS 可能顺带检查多个课程，后续读到颜色 `2` 时就跳过。

## 三、电话号码的字母组合：按位置选字母

结论：每一层递归负责给电话号码的**一个位置**选字母。`path` 保存正在拼的组合；填满全部位置时，把它变成字符串加入 `ans`。

### 逐段看代码

```python
MAPPING = "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"
```

这个逗号分隔的表达式是元组，`MAPPING[2]` 是 `"abc"`，`MAPPING[3]` 是 `"def"`；索引 0、1 用空字符串占位。`digits[i]` 是字符，例如 `"2"`，要转成整数才能用作下标。

```python
n = len(digits)
if n == 0:
    return []
ans = []
path = [""] * n
```

空输入直接得到空列表。`ans` 存放最终结果；`path` 一开始就有 `n` 个位置，之后通过 `path[i] = c` **覆盖**对应位置。

```python
def dfs(i: int) -> None:
    if i == n:
        ans.append("".join(path))
        return
    for c in MAPPING[int(digits[i])]:
        path[i] = c
        dfs(i + 1)
```

`dfs(i)` 的任务是：在前 `i` 个位置已有选择的基础上，填好从位置 `i` 开始的所有组合。`i == n` 表示每个位置都选完；`"".join(path)` 把字符列表拼成一个结果。循环依次尝试当前数字对应的各个字母，递归填下一个位置；上一条分支返回后，下一次循环会覆盖 `path[i]`，所以这份固定长度列表写法无需 `pop()`。

最后 `dfs(0)` 从第 0 位开始搜索，`return ans` 交出所有结果。

### 用 `digits = "23"` 手推

`n = 2`，`path = ["", ""]`。第 0 位从 `abc` 中选，第 1 位从 `def` 中选：

| 第 0 位 | 第 1 位依次选择 | 加入 `ans` |
| --- | --- | --- |
| `a` | `d`、`e`、`f` | `ad`、`ae`、`af` |
| `b` | `d`、`e`、`f` | `bd`、`be`、`bf` |
| `c` | `d`、`e`、`f` | `cd`、`ce`、`cf` |

例如先走 `a → d`，`path = ["a", "d"]`，加入 `"ad"`；返回后在同一个位置写入 `e`，得到 `"ae"`。第 0 位换成 `b` 时也只是覆盖 `path[0]`，然后重新枚举第 1 位。

### 递归究竟“回”到了哪里

每次 `return` 只结束**当前这一层调用**，回到直接调用它的地方。对于 `digits = "23"`：

```text
letterCombinations
  └─ dfs(0)：第 0 位选 a
       └─ dfs(1)：第 1 位选 d
            └─ dfs(2)：保存 ad，然后 return
       dfs(1) 的 for 循环继续：第 1 位改选 e，保存 ae；再改选 f，保存 af
  dfs(1) 结束，回到 dfs(0) 的 for 循环：第 0 位改选 b
```

所以“回溯”发生在子调用返回后，上一层从暂停的 `for` 循环继续试下一个字母。它不会从 `dfs(2)` 一次跳回 `dfs(0)`。所有分支完成后，`dfs(0)` 才返回外层的 `letterCombinations`。如果只要找到一个结果就停止整个搜索，可以让每层返回布尔值，并由调用它的上一层继续把停止信号向上传；本题要求全部组合，因此不能提前停止。

`path` 也不会在 `return` 时自动恢复。例如保存 `"af"` 后，`path` 仍是 `["a", "f"]`；回到 `dfs(0)` 选 `b` 时先变成 `["b", "f"]`，随后进入 `dfs(1)`，第 1 位选 `d` 并覆盖 `f`，才变成 `["b", "d"]`。由于只有 `i == n` 才保存结果，残留的 `f` 不会被误存。

### 三个语法点与固定长度 `path`

- `MAPPING = "", "", "abc", ...` 是一个元组；前两个空字符串占据下标 `0`、`1`，因此 `MAPPING[2]` 正好是 `"abc"`。
- 当 `digits = "23"`、`i = 0` 时，`digits[i]` 是字符 `"2"`；`int(digits[i])` 变成整数 `2`，才能作元组下标。
- `"".join(["a", "d"])` 得到新字符串 `"ad"`；前面的 `""` 是空分隔符。加入 `ans` 的字符串不会因随后修改 `path` 而变化。
- `path = [""] * n` 先创建 `n` 个可写位置，才能执行 `path[i] = c`。若 `path = []`，直接给 `path[0]` 赋值会越界。另一种写法可从空列表开始，但需要 `append` 增加字母，并在返回后 `pop` 撤销。
