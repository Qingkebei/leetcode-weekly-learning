## 二、值得带到下一周的易错点

| 题目 / 概念 | 当时的问题 | 这次形成的理解 |
| --- | --- | --- |
| 105. 前中序建树 | 能说出找根，但不知道递归如何落笔 | 中序根下标 `i` 是左子树节点数；据此划分前序，递归返回子树根后接到 `left/right` |
| 114. 展开二叉树 | 收集 `node.val` 后赋给 `right`；重复覆盖同一个根 | 结构连接需要节点对象；右、左、根倒序处理，再向链头插入 |
| 230. 第 K 小 | 把减一放在 `k == 0` 判断之后 | 先把当前节点计入访问数量，再判断；否则晚一个节点记录答案 |
| 200. 岛屿数量 | 外层扫描还在第一行，为何第二行已标记 | 外层找起点，DFS 通过新的行列坐标跨行扩展；内层函数直接使用外层 `grid` |
| 994. 腐烂的橘子 | 如何表示同时传播的时间 | 全部初始腐烂橘子一起入队；`tmp` 处理当前层，新 `q` 收集下一层 |
| 207. 课程表 | 将完成标记写成 `colors[y] = 2`；混淆两个布尔返回值 | `dfs(x)` 检查完所有后续课程后标记 `x`；DFS 的 `True` 是有环，外层的 `False` 是无法学完 |
| 207. 三种颜色 | 把 `0` 理解为“没有作为外层起点” | `0` 是从未访问，`1` 是仍在当前递归路径上，`2` 是已检查完成；外层循环覆盖各独立部分 |
| 17. 组合回溯 | 不知道递归返回到了哪里 | `return` 回到直接调用自己的那一层；上一层的 `for` 从暂停处继续选下一个字母 |
| 17. `path` | 为什么要先写 `[""] * n`，为什么没有 `pop` | 预留位置才能索引赋值；每层覆盖当前位置，只有所有位置填满后才保存结果 |
| 208. Trie | 每个类中的 `self` 指向什么 | `Node` 方法中的 `self` 是当前节点，`Trie` 方法中是整棵 Trie；`cur` 是沿路径移动的临时引用 |
| 45. 跳跃游戏 II | 最远位置与跳跃次数如何联系 | 当前边界 `cur_reach` 与下一跳最远位置 `right_reach` 分开；扫描到边界时才增加步数 |
| 35 / 74. 二分 | `//` 及二维坐标转换 | `//` 向下取整；每行 `n` 列时，一维下标对应行 `mid // n`、列 `mid % n` |

Python 语法也已逐步拆开理解：列表推导式可以改写成 `for + append`；`enumerate` 同时给出下标与当前值；`int` 把数字字符变成下标；`join` 将字符列表拼成新字符串。后续遇到复杂一行代码时，先展开成普通循环或分支。
